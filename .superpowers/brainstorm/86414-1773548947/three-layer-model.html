Layer 3 — Per-Object Semantic Channels

Object Semantic Data

Objects expose abstract properties. Style transforms act on these, not on object internals.

Per-Vertex / Per-Instance
Shared Channels (all objects)
curvature

How Style Uses Them
softness × edge_sharpness → smooths all edges
exaggeration × curvature → amplifies all curves
surface_detail × surface_noise → reduces noise
Works on trees, rocks, ground — any object

Palette System

Separate from the three layers, a palette mapping forces all object colors into a curated family. Objects output raw base colors. The style system remaps them through palette slots.

What Changed From Previous Design

Before
  • ~25 raw knobs exposed directly to user
  • Per-material shader paths (trunk/foliage/ground)
  • Color control via saturation + hue shift
  • No abstraction between user intent and GPU params
After
  • ~8-12 style axes → mapped to GPU params
  • Semantic channels make styles object-agnostic
  • Palette system for color cohesion
  • Clean separation: intent → parameters → transforms
