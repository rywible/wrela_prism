Pass 2 — HW Raster ★ MODIFIED
Geometry Deformation
Reads ArtDirectionUniforms tier 1 params
New behavior: After standard vertex transform, apply:
  • silhouette_inflate × vertex curvature channel → push outward along normal
  • normal_smoothing × vertex edge_sharpness → blend toward averaged normals
  • detail_suppression × vertex surface_noise → dampen high-freq displacement
All zero = current behavior. Smooth interpolation = runtime morphing.

Pass 6 — Material Resolve ★ MAJOR CHANGES
Shading Transforms + Palette
Reads ArtDirectionUniforms tier 2 params + palette buffer
Pipeline within the shader:

1. Existing PBR — full Lambertian + Cook-Torrance + SSS runs as-is → produces raw_light

2. NEW: Light banding — quantize raw_light into shading_bands steps with band_softness smoothstep

3. NEW: Shadow color shift — where light < threshold, blend toward shadow_color_shift

4. NEW: Rim lighting — fresnel-based edge glow scaled by rim_light_strength

5. NEW: Palette remap — base_color runs through palette LUT, blended by color_discipline

6. NEW: Specular flatten — lerp specular toward zero by specular_flattening

Order matters: PBR first (high fidelity), then style transforms (controlled degradation).

Pass 9.5 — Outline ★ NEW PASS
Screen-Space Edge Detection
Reads depth buffer + normal buffer → detects edges → composites outlines
Technique: Sobel/Roberts on depth + normals
  • outline_depth_sensitivity — edge weight from depth discontinuities (silhouettes)
  • outline_normal_sensitivity — edge weight from normal discontinuities (surface detail)
  • outline_thickness — kernel size / dilation
  • outline_strength — final blend (0 = invisible, 1 = full ink)
  • outline_color — typically near-black for anime
When outline_strength = 0, this pass is a no-op (early-out).
