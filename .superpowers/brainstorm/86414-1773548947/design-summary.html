Art Direction System — Full Design Summary

Everything we've agreed on, in one view

Architecture: Style Transform Stack (3 Layers)

Layer 1: Style Axes

~8-12 high-level knobs (softness, exaggeration, shadow_graphicness, etc). User-facing and game-facing API. Interpolatable for runtime morphing.

→
Layer 2: GPU Params

~25 raw params in ArtDirectionUniforms. Derived from axes via mapping functions. Separate uniform buffer bound to shaders.

→
Layer 3: Semantic Channels

Per-vertex data (curvature, edge_sharpness, surface_noise, importance). Packed as u32. Style transforms act on these, not object internals.

Key Design Decisions

Philosophy
  • High-fidelity simulation → controlled degradation
  • PBR runs fully, style transforms applied on top
  • All defaults = identity (current photorealistic look)
  • Style is a gameplay system, not just a dev tool
Technical
  • Separate ArtDirectionUniforms buffer (not extending LightingUniforms)
  • Per-object overrides via prototype-indexed buffer
  • All knobs are floats/vec3s — everything interpolates
  • Vertex deformation (no regeneration) for runtime geometry morphing

Runtime API — Two Consumers

Gameplay (Programmatic)
transition_to(style, duration, curve)
set_blend([(style_a, weight), ...])
drive_axis(axis, value)

Examples: flow state → watercolor, death → monochrome, biome transitions, combat intensity driving shadow_graphicness
Harness (Authoring)
F5 — cycle style snapshots
F6 — inspector overlay
[ / ] — blend slider
0 — reset to photorealistic
CLI: --style, --style-blend

Used to author and tune styles that gameplay later drives

Palette System

9 curated color slots (shadow, dark, mid, light, accent, bark, foliage, earth, sky_tint). Objects output raw base colors. Shader remaps via luminance-based tonal slot matching + material-hint blending. color_discipline axis controls blend strength (0 = raw colors, 1 = fully palette-mapped). Palette slots are vec3s — interpolatable for morphing between palettes.

First Target: Demon Slayer Style

The implementation validates the system by building one complete style: soft gradient banding (~3-4 steps), purple-shifted shadows, strong warm rim lights, curated palette (deep greens, warm bark, purple shadow tones), variable-weight ink outlines on silhouettes, warm bloom tint, slight geometry inflation for bold silhouettes, gentle specular flattening. When all axes are at zero, the renderer produces its current photorealistic output — unchanged.
